# System Programming Algorithms

Operating system concepts and scheduling algorithms implemented in C++.

## CPU Scheduling

**Implemented Algorithms**
- First Come First Serve (FCFS)
- Round Robin scheduling
- CPU and process management

**OS Simulators**
- Complete OS simulator (v1.0, v1.1, v2.0)
- Process, CPU, and memory management integration
- Process management with physical memory access

## Memory Management

- Paging simulator (v1.0, v1.1)
- Virtual-to-physical address mapping
- Page replacement algorithms

## Resource Management

- Banker's Algorithm – Deadlock avoidance
- Resource allocation and process safety
